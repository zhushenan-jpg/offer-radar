
# OfferRadar 全浏览器操作整改方案

## 目标
将所有操作迁移到浏览器界面，用户无需编辑配置文件或使用命令行。

## 整改内容

### 1. 新增统一应用入口 (`app.py`)
- 合并 dashboard.py 和 monitoring.py 为一个完整应用
- 添加侧边栏导航
- 一键启动：`streamlit run src/jobpilot/app/app.py`

### 2. 新增设置页面 (`pages/1_设置.py`)
- **API Key 配置**：文本输入框，保存到 .env
- **模型选择**：下拉框选择模型
- **预算设置**：数字输入框设置月度预算
- **通知配置**：邮件/webhook 配置

### 3. 新增简历编辑页面 (`pages/2_我的简历.py`)
- **基础信息**：姓名、技能、工作年限、学历
- **简历内容**：Markdown 编辑器
- **求职意向**：期望岗位、城市、远程、薪资
- **PDF 上传**：支持上传 PDF 自动解析

### 4. 新增在线评分页面 (`pages/3_在线评分.py`)
- **粘贴 JD**：文本框直接粘贴职位描述
- **上传 JD 文件**：支持 .md/.txt 文件上传
- **一键评分**：点击按钮即时评分
- **结果展示**：显示评分、证据链、Gap 分析

### 5. 新增目标公司管理页面 (`pages/4_目标公司.py`)
- **公司列表**：展示当前监控的公司
- **添加公司**：输入公司名、平台（Greenhouse/Lever）、slug
- **删除公司**：一键删除
- **批量导入**：支持 JSON/YAML 批量导入

### 6. 新增一键采集页面 (`pages/5_一键采集.py`)
- **开始采集**：点击按钮触发采集
- **采集进度**：实时显示采集状态
- **结果预览**：展示采集到的职位

### 7. 保留现有功能
- 概览页面（已有）
- 职位与评分页面（已有）
- 待人工复核页面（已有）
- 周报页面（已有）
- 评测页面（已有）
- 监控面板（已有，合并进来）
