# OfferRadar 用户测试指南

> 测试目标：验证系统的易用性和功能完整性
> 预计时间：30-60 分钟

---

## 一、环境准备

### 1.1 安装 Python

```bash
# 检查 Python 版本（需要 3.11 或 3.12）
python --version

# 如果没有安装，下载地址：
# https://www.python.org/downloads/
```

### 1.2 克隆项目

```bash
git clone https://github.com/zhushenan-jpg/offer-radar.git
cd offer-radar
```

### 1.3 创建虚拟环境

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# macOS/Linux
python3 -m venv .venv
source .venv/bin/activate
```

### 1.4 安装依赖

```bash
pip install -e ".[dev,m2,m3]"
```

### 1.5 启动应用

```bash
streamlit run src/jobpilot/app/app.py
```

启动后浏览器自动打开 `http://localhost:8503`

## 二、测试任务

### 任务 1：配置 API Key（5 分钟）

1. 点击左侧 **⚙️ 设置**
2. 输入你的 API Key（智谱 AI 或其他兼容端点）
3. 点击 **💾 保存配置**
4. 刷新页面验证配置生效

**验证点**：
- [ ] API Key 输入框可用
- [ ] 保存按钮可点击
- [ ] 刷新后配置保持

---

### 任务 2：编辑简历（10 分钟）

1. 点击左侧 **📝 我的简历**
2. 填写或修改以下信息：
   - 姓名
   - 学历
   - 技能（每行一个）
   - 简历内容（Markdown 格式）
   - 期望岗位
   - 期望城市
3. 点击 **💾 保存简历**
4. 展开 **👁️ 简历预览** 查看效果

**验证点**：
- [ ] 表单可正常填写
- [ ] 保存按钮可点击
- [ ] 预览显示正确

---

### 任务 3：在线评分（10 分钟）

1. 点击左侧 **📊 在线评分**
2. 在文本框中粘贴以下 JD：

```
职位名称：后端开发实习生

公司简介：
我们是一家专注于云计算的科技公司...

岗位职责：
1. 负责后端 API 设计与开发
2. 参与系统架构设计和优化
3. 编写技术文档

任职要求：
1. 熟悉 Python 或 Java
2. 了解 MySQL、Redis 等数据库
3. 有 Docker 使用经验优先
4. 每周至少 4 天，实习 3 个月以上
```

3. 点击 **🚀 开始评分**
4. 等待评分完成

**验证点**：
- [ ] 文本框可粘贴
- [ ] 评分按钮可点击
- [ ] 评分结果显示（综合分数、维度评分、证据链）

---

### 任务 4：目标公司管理（5 分钟）

1. 点击左侧 **🏢 目标公司**
2. 查看当前监控的公司列表
3. 尝试添加一个新公司：
   - 公司名称：Google
   - 招聘平台：greenhouse
   - 平台标识：google
4. 点击 **➕ 添加公司**
5. 尝试删除一个公司

**验证点**：
- [ ] 公司列表正常显示
- [ ] 添加公司功能可用
- [ ] 删除公司功能可用

---

### 任务 5：语言切换（5 分钟）

1. 在左侧侧边栏找到 **🌐 Language** 下拉框
2. 从"中文"切换到"English"
3. 观察页面内容是否切换为英文
4. 切换回"中文"

**验证点**：
- [ ] 下拉框可选择
- [ ] 切换后页面内容更新
- [ ] 切换回中文正常

---

### 任务 6：查看职位列表（5 分钟）

1. 点击左侧 **📋 职位列表**
2. 查看已评分的职位
3. 尝试筛选（按公司、按职位名称）
4. 点击一个职位查看详情

**验证点**：
- [ ] 职位列表正常显示
- [ ] 筛选功能可用
- [ ] 职位详情正常显示
