# OfferRadar 用户使用手册

> 版本: v2.0 (2026-09-08)
> 适用对象: 计算机专业学生（求职/实习/校招）

---

## 一、系统简介

OfferRadar 是一个**全浏览器操作**的智能求职助手：

1. **在线评分** - 粘贴 JD 文本，立即获得匹配评分
2. **证据链分析** - 自动提取简历中的可验证声明
3. **差距识别** - 找出简历与职位要求的差距
4. **公司监控** - 持续监控目标公司的职位发布
5. **成本控制** - 精确计量 API 调用成本

**核心原则**: 只辅助决策，不自动投递，不爬取 LinkedIn。

---

## 二、快速开始（3 步完成）

### 第 1 步：启动应用

```bash
# 方式 1：直接启动（推荐）
cd offer-radar
.venv\Scripts\streamlit run src/jobpilot/app/app.py

# 方式 2：Docker 启动
docker compose up -d
```

启动后浏览器自动打开 `http://localhost:8503`

### 第 2 步：配置 API Key

1. 点击左侧导航栏的 **⚙️ 设置**
2. 输入你的 **API Key**（智谱 AI 或其他兼容端点）
3. 点击 **💾 保存配置**

### 第 3 步：开始使用

1. 点击 **📝 我的简历** - 编辑你的个人信息
2. 点击 **📊 在线评分** - 粘贴 JD 文本评分
3. 点击 **📋 职位列表** - 查看评分结果

## 三、功能详解

### 3.1 概览页面

显示系统状态和快速入口：
- 配置状态（API Key、简历、公司、评分）
- 快速开始指南
- 功能介绍

### 3.2 设置页面

**API 配置**
- API Key：必填，用于调用 AI 模型
- API 地址：默认智谱 AI，可改为其他兼容端点
- 模型选择：glm-5.3-flash（推荐）、glm-4-flash 等
- 月度预算：设置每月 API 费用上限

**通知配置（可选）**
- 启用邮件通知
- 配置 SMTP 服务器
- 设置收件人

### 3.3 简历编辑页面

**基础信息**
- 姓名、工作年限、学历
- 技能列表（每行一个）

**简历内容**
- Markdown 格式编辑
- 支持项目经历、实习经历、技能等
- 实时预览

**求职意向**
- 期望岗位、城市
- 远程偏好、薪资范围

### 3.4 在线评分页面

**输入方式**
- 粘贴文本：直接粘贴 JD 内容
- 上传文件：支持 .md/.txt 格式

**评分结果**
- 综合匹配分数（0-100）
- 四维度评分（技能/经验/约束/成长）
- 证据链分析
- 差距识别和改进建议

### 3.5 目标公司管理

**查看现有公司**
- 表格展示所有监控公司
- 显示平台类型（Greenhouse/Lever）

**添加公司**
- 输入公司名称
- 选择平台类型
- 输入平台标识（slug）

**删除公司**
- 多选后批量删除

**批量导入**
- 支持 YAML 格式批量导入

### 3.6 一键采集

**采集选项**
- 增量采集：只获取新职位
- 全量采集：更新所有职位

**采集进度**
- 实时显示采集状态
- 展示各公司采集结果

### 3.7 职位列表

**筛选功能**
- 按公司筛选
- 按职位名称搜索

**职位详情**
- 综合评分和维度评分
- 证据链详情
- 原始职位链接

### 3.8 监控面板

**系统指标**
- Claim 提取数量
- 简历补丁数量
- 面试速览数量

**成本分析**
- 各模块成本明细
- 扩展技能成本

**评分分布**
- 分数段分布图

## 四、常见问题

### Q1: 启动后浏览器没有自动打开？

手动访问：`http://localhost:8503`

### Q2: API Key 配置后还是提示未配置？

刷新页面或重启 Streamlit 应用。

### Q3: 评分失败怎么办？

检查：
1. API Key 是否正确
2. 网络是否正常
3. API 余额是否充足

### Q4: 如何添加更多公司？

访问「🏢 目标公司」页面，输入公司信息后点击添加。

### Q5: 如何查看历史评分？

访问「📋 职位列表」页面，可筛选和搜索历史评分。
