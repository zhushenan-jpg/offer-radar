## 版本发布流程

1. **开发**：在 feature 分支开发
2. **测试**：运行单元测试 + 集成测试
3. **审查**：代码审查通过
4. **合并**：合并到 main 分支
5. **打标签**：创建 Git tag
6. **发布**：更新 CHANGELOG.md
7. **部署**：部署到生产环境
