# OfferRadar 部署指南

## 方案一：Streamlit Community Cloud（推荐）

### 优点
- 免费
- 无需服务器配置
- 自动 HTTPS
- 支持 GitHub 集成

### 部署步骤

1. **准备 GitHub 仓库**
   - 仓库地址：https://github.com/zhushenan-jpg/offer-radar
   - 确保代码已推送到 main 分支

2. **访问 Streamlit Cloud**
   - 打开 https://share.streamlit.io
   - 使用 GitHub 账号登录

3. **创建应用**
   - 点击 "New app"
   - 选择仓库：zhushenan-jpg/offer-radar
   - 选择分支：main
   - 主文件路径：src/jobpilot/app/app.py
   - 点击 "Deploy!"

4. **配置 Secrets**
   - 在应用页面点击 "Settings" → "Secrets"
   - 添加以下内容：

```toml
# API 配置
ZHIPU_API_KEY = "your-api-key-here"
OPENAI_BASE_URL = "https://open.bigmodel.cn/api/paas/v4/"
JOBPLOT_MODEL = "glm-5.3-flash"

# 预算配置
JOBPLOT_MONTHLY_BUDGET_CNY = "30"
```

5. **完成部署**
   - 应用将自动部署
   - 访问地址：https://your-app-name.streamlit.app

## 方案二：本地 Docker 部署

### 部署步骤

1. **安装 Docker**
   - Windows：下载 Docker Desktop
   - macOS/Linux：安装 Docker Engine

2. **克隆项目**
   ```bash
   git clone https://github.com/zhushenan-jpg/offer-radar.git
   cd offer-radar
   ```

3. **配置环境变量**
   ```bash
   cp .env.example .env
   # 编辑 .env 文件，填入 API Key
   ```

4. **启动服务**
   ```bash
   docker compose up -d
   ```

5. **访问应用**
   - 浏览器访问：http://localhost:8501

## 方案三：云服务器部署

### 推荐配置
- 阿里云/腾讯云轻量应用服务器
- 2 核 4GB 内存
- 50GB 系统盘
- Ubuntu 22.04

### 部署步骤

1. **安装 Docker**
   ```bash
   curl -fsSL https://get.docker.com | sh
   sudo usermod -aG docker $USER
   ```

2. **克隆项目**
   ```bash
   git clone https://github.com/zhushenan-jpg/offer-radar.git
   cd offer-radar
   ```

3. **配置环境变量**
   ```bash
   cp .env.example .env
   nano .env
   # 填入 API Key 和其他配置
   ```

4. **启动服务**
   ```bash
   docker compose up -d
   ```

5. **配置 Nginx 反向代理**
   ```nginx
   server {
       listen 80;
       server_name your-domain.com;

       location / {
           proxy_pass http://localhost:8501;
           proxy_http_version 1.1;
           proxy_set_header Upgrade $http_upgrade;
           proxy_set_header Connection "upgrade";
           proxy_set_header Host $host;
       }
   }
   ```

6. **配置 SSL（Let's Encrypt）**
   ```bash
   sudo apt install certbot python3-certbot-nginx
   sudo certbot --nginx -d your-domain.com
   ```

7. **配置定时任务**
   ```bash
   # 添加定时采集任务
   crontab -e
   # 每天 07:30 执行增量采集
   30 7 * * * cd /path/to/offer-radar && docker compose exec offer-radar python -m jobpilot watch --once
   ```

## 常见问题

### Q: 部署后无法访问？
A: 检查防火墙设置，确保端口 8501 或 80/443 已开放。

### Q: API Key 配置后仍提示未配置？
A: 检查 .env 文件格式，确保没有多余空格或引号。

### Q: Docker 容器启动失败？
A: 运行 `docker compose logs` 查看错误日志。
